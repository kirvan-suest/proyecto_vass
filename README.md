<h1 data-importer="text" align="left">Proyecto Vass</h1>

###

<p data-importer="text" align="left">
  Este proyecto es una prueba técnica. 
  
  * La primer fase de la prueba consiste en desarrollar una página web en Java que reciba una palabra y valide si esa palabra es un palíndromo. 
  
    Si la palabra ingresada es un palíndromo se desplegara un mensaje:
  
    '¡La palabra '[palabra]' es palíndromo.!' 
  
    en caso de no serlo un palíndromo se desplegara el mensaje:
    
    '¡La palabra '[palabra]' NO es palíndromo.!'.
  
  * En la segunda fase se realizará la automatización del validador de palabras, ingresando valores validos e inválidos.</p>
